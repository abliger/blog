#### 主键约束

主键的特点：

主键是非空且唯一的，可以多列组合值唯一

自动简历索引

删除时只会进行删除索引，非空约束不会还原

```java
/*建表时添加主键*/
create table 表名(
  字段名 字段类型 primary key
);
create table 表名(
  字段名1 字段类型,
    字段名2 字段类型,
    primary key(字段名1,字段名2)
);
alter table 表名 add primary key(字段名);
alter table 表名 drop primary key;
```


#### 唯一键约束

唯一键特点

唯一键可以为空且可以有多个，可以多列组合值唯一

唯一键能自动建立索引

删除唯一键时需要知道唯一键的索引名

```java
create table 表名(
  字段名 字段类型 unique key
);
create table 表名(
  字段名1 字段类型 ,
    字段名2 字段类型,
    unique key(字段名1,字段名2)
);
alter table 表名 add unique key(字段名);
alter table 表名 drop index 唯一键约束名;
/*
唯一键约束名和字段名可能不同，需要通过show index from 表名称 查看
*/
```


#### 外键约束

外键约束的特点：

建立外键需要主表存在

可以建立多个外键约束

从表引用主表的键列(主键、唯一键、外键)且数据类型要相同

删除外键时，关于外键列上的普通索引需要单独删除。

外键约束导致：

1. 主表的修改和删除受限
2. 从表的添加修改受限

约束等级：

（1）restrict：严格的模式

一旦主表被从表引用了：

A：主表的删除就被限制了

B：主表被引用字段的修改被限制了

C：主表被引用字段的记录的删除被限制了

（2）no action，在mysql中，它和restrict一样

（3）set null

一旦主表被从表引用了：

A：主表不能先删除

B：主表被引用字段的修改了，从表对应的外键字段设置为null

C：主表被引用字段的记录的删除，从表对应的外键字段设置为null

要求：从表的外键字段不能是非空的

（4）cascade

一旦主表被从表引用了：

A：主表不能先删除

B：主表被引用字段的修改了，从表对应的外键字段跟着自动修改

C：主表被引用字段的记录的删除，从表对应的记录跟着删除

```java
create table 表名(
  字段1 字段类型 ,
    foreign key (从表字段) refereces 主表名(主表字段) on update 约束等级 on delete 约束等级
);
alter table 表名 add foreign key (从表字段名) references 主表名(主表字段)on update 约束等级 on delete 约束等级;
alter table 表名 drop foreign key 外键约束名；
/*
select * from information_schema.table_constraints where
talbe_name="表名称";
*/
```


#### 非空约束

```java
create table 表名(
  字段名2 数据类型 【unique key】 【not null】
);
alter table 表名 modify 字段名 字段类型 not null;
alter table 表名 modify 字段名 字段类型;
```


#### 默认值约束

```java
create table 表名(
  字段名2 数据类型  default 默认值,
    foreign key(字段名称) references 主表名 (主表字段) on update cascade on delete set null
);
alter table 表名 modify 字段名 字段类型 default 默认值;
alter table 表名 modify 字段名 字段类型;
```


#### 自增约束

自增约束的特点：

一个表中只能由一个自增约束

自增约束列只能是键列，且非空

类型只能是整型

可以手动插入，如果插入null或空，可会继续增长

```java
create table 表名(
  字段名 字段类型 primary key auto_increment
);
alter table 表名 modify 字段名 字段类型 aotu_increment;
alter table 表名 modify 字段名 字段类型;
```


#### 几个约束的添加

1、如果某列有自增约束，怎么添加该字段的值

添加数据时，对于自增列

```java
insert into 【数据库名.]表名称 values(值列表)；#在值列表中，对应自增列可以赋值为null和0
insert into 【数据库名.]表名称(部分字段列表) values(值列表)；#自增列在(部分字段列表)中不写就可以
```


2、如果某列有默认值约束，怎么添加、修改该字段的值

添加数据时，对于有默认值列

```java
insert into 【数据库名.]表名称 values(值列表)；#在值列表中，对应默认值列，如果想用默认值，用default
insert into 【数据库名.]表名称(部分字段列表) values(值列表)；#对应默认值列，如果想用默认值，在(部分字段列表)中不写就可以
```


修改数据

```java
update 【数据库名.]表名称 set 字段名1 = 值1, 字段名2 = 值2 。。。 【where 条件】; #对应默认值列，如果想用默认值，写字段名 = default就可以
```
