## 什么是AJAX

AJAX = Asynchronous JavaScript and XML（[异步](../异步/异步.md "异步")的 JavaScript 和 XML）。

AJAX 不是新的编程语言，而是一种使用现有标准的新方法。

可以在页面不刷新（局部刷新）的情况下，请求服务器，局部更新页面的数据

本质:是在HTTP协议的基础上以异步的方式通过XMLHttpRequest对象与服务器进行通信。
