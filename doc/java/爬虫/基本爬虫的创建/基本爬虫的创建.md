# 基本爬虫的创建

不带参数的url访问

```java
CloseableHttpClient httpClient = HttpClients.createDefault();
//使用get请求
HttpGet httpGet = new HttpGet("https://www.jianshu.com/p/82f30208ae56");
//获得响应对象
CloseableHttpResponse response = null;
try {
    response = httpClient.execute(httpGet);
    //判断响应码
    if (response.getStatusLine().getStatusCode() == 200) {
        //获得页面内容
        HttpEntity entity = response.getEntity();
        //使用工具类打印
        String s = EntityUtils.toString(entity,"utf8");
        System.out.println(s);
    }
} catch (IOException e) {
    e.printStackTrace();
}finally {
    try {
        assert response != null;
        response.close();
    } catch (IOException e) {
        e.printStackTrace();
    }finally {
        try {
            httpClient.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
} 
```


带参数url地址访问

```java
//得到客户端
CloseableHttpClient httpClient = HttpClients.createDefault();
//使用uriBuilder创建  url=https://zhidao.baidu.com/daily/view?id=224120
URIBuilder uriBuilder = new URIBuilder("https://zhidao.baidu.com/daily/view");
//使用addParameter添加参数，并返回该对象
uriBuilder.addParameter("id","224120");
//.addParameter("id","1");
//使用get请求
HttpGet httpGet = new HttpGet(uriBuilder.build());
CloseableHttpResponse response = httpClient.execute(httpGet); 
```

带参数的post请求

带参数post请求使用表单提交

```java
CloseableHttpClient httpClient = HttpClients.createDefault();
//使用get请求
HttpPost httpPost = new HttpPost("https://www.jianshu.com/p/82f30208ae56");
//使用list集合封装请求参数
List<NameValuePair> params=new ArrayList<>();
params.add(new BasicNameValuePair("keys","java"))
//创建post请求的entity对象
 UrlEncodedFormEntity entity=new  UrlEncodedFormEntity(params,"utf8")
 //设置entity对象到post请求中
 httpPost.setEntity(entity);
//获得响应对象
CloseableHttpResponse response = null;
try {
    response = httpClient.execute(httpPost);

    e.printStackTrace();

        e.printStackTrace();

        try {
            httpClient.close();

            e.printStackTrace();
        }
    }
```
