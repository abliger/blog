## filter

filter 属性是 CSS 中用于应用图形效果的复合属性。它可以接受多个函数，每个函数之间用空格分隔。
示例：

```css
.image {
  filter: brightness(50%) contrast(200%) blur(2px);
}
```

### 常用的滤镜函数

1. blur() 使图像产生模糊效果。

```css
.blur {
  filter: blur(5px);
}
```

2. brightness()
   调整图像的亮度。值可以是 0%（完全黑）到 100%（原始亮度）之间的百分比，或者超过 100%（更亮）。

```css
.brightness {
  filter: brightness(75%);
}
```

3. contrast()
   调整图像的对比度。值可以是 0%（无对比度）到 100%（原始对比度）之间的百分比，或者超过 100%（更高对比度）。

```css
.contrast {
  filter: contrast(200%);
}
```

4.  grayscale()
    将图像转换为灰度图像。值可以是 0%（无效果）到 100%（完全灰度）。

```css
.grayscale {
  filter: grayscale(100%);
}
```

5.  hue-rotate()
    旋转图像的色相。值是角度，例如 90deg 将图像的色相旋转 90 度。

```css
.hue-rotate {
  filter: hue-rotate(90deg);
}
```

6. invert() 反转图像的色彩。值可以是 0%（无效果）到 100%（完全反转）。

```css
.invert {
  filter: invert(100%);
}
```

7.  opacity() 和 sepia()
    等其他滤镜效果也可以单独使用或与其他滤镜组合使用，以创建复杂的效果。例如：

```css
.sepia {
  filter: sepia(100%); /* 转换为棕褐色 */
}
```
