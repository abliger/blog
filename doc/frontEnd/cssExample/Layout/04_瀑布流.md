对于高度不同的 item 进行瀑布流布局


1‌‌.‌ ‌CSS Column-count 多栏布局‌
‌原理‌：通过column-count属性将内容分成多列，column-gap设置列间距。
‌优点‌：实现简单，代码量少，适合静态内容展示。
‌缺点‌：列数固定，无法动态加载新内容；排列顺序是先从上到下，再从左到右，可能导致内容被截断。‌
‌适用场景‌：适合内容固定且不需要动态加载的页面。

:::demo src=frontEnd/cssExample/Layout/example/WaterfallFlow.vue
:::

‌Flex 布局‌
‌原理‌：使用flex布局，通过flex-wrap属性实现换行，并手动调整元素顺序。
‌优点‌：支持动态换行，布局灵活，适合内容动态加载的场景。
‌缺点‌：需要手动调整元素顺序，实现稍复杂；对性能有一定影响。‌
‌适用场景‌：适合需要动态加载内容且布局要求较高的页面。

:::demo src=frontEnd/cssExample/Layout/example/WaterfallFlowByFlex.vue
:::
