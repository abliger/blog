# html 标签

## 元数据

1. `head` 标签: `head` 标签是所有头部标签的容器.包含文档的标题(title),可以包含脚本、样式、meta 信息 以及其他更多的信息.
2. `title` 标签: `title` 标签定义文档的标题
3. `base` 标签: `base` 标签为页面上的所有的相对链接规定默认 URL 或默认目标.
4. `link` 标签: `link` 标签定义文档与外部资源的关系.最常见的用途是链接样式表.
5. `meta` 标签: `meta` 标签指定网页的描述,关键词,文件的最后修改时间,作者及其他元数据.
6. `style` 标签: `style` 标签定义 HTML 文档的样式信息.

## 结构标签

1. `html` 标签: `html` 标签告知浏览器这是一个 HTML 文档.`html` 标签是 HTML 文档中最外层的标签.
2. `body` 标签: `body` 标签定义文档的主体. `body` 标签包含文档的所有内容(比如文本、超链接、图像、表格和列表等等).
3. `article` 标签: `article` 标签定义独立的内容.如新闻、博客文章.
4. `section` 标签: `section` 标签定义了文档的某个区域.比如章节、头部、底部或者文档的其他区域.
5. `nav` 标签: `nav` 标签定义导航链接的部分.
6. `h` 标签: `h` 标签定义 1~6 级标题.
7. `header` 标签: `header` 标签定义文档或者文档的一部分区域的页眉.`header` 标签不能被放在 `footer`、`address` 或者另一个 `header` 标签内部.
8. `footer` 标签: `footer` 标签定义文档或者文档的一部分区域的页脚.该标签会包含文档创作者的姓名、文档的版权信息、使用条款的链接、联系信息等等.
9. `address` 标签: `address` 标签定义文档作者/所有者的联系信息.
   如果 `address` 标签位于 `body` 标签内部,则它表示该文档作者/所有者的联系信息.
   如果 `address` 标签位于 `article` 标签内部,则它表示该文章作者/所有者的联系信息.
   `address` 标签的文本通常呈现为斜体.大多数浏览器会在该标签的前后添加换行.
10. `aside` 标签: `aside` 标签定义 `article` 标签外的内容.通常放在文档的侧边栏中.

## 内容标签

1. `p` 标签: `p` 标签代表一个段落.
2. `hr` 标签: `hr` 标签表示段落级主题中断,例如故事中的场景变化,或过渡到参考书部分中的另一个主题.
3. `pre` 标签: `pre` 标签表示一个预格式化的文本块,被包围在 `pre` 标签中的文本通常会保留空格和换行符.而文本也会呈现为等宽字体.
4. `blockquote` 标签: `blockquote` 标签表示来自其他来源引用的内容,可选的引用必须在 `footer` 或 `cite` 标签内,可选的内联更改,如注释和缩写.
5. `ol` 标签: `ol` 标签表示有序列表.
6. `ul` 标签: `ul` 标签表示无序列表.
7. `li` 标签: `li` 标签表示一个列表项. `li` 可用在有序列表(`ol`)、无序列表(`ul`)和菜单列表(`menu`)中
8. `dl` 标签: `dl` 标签定义一个描述列表. `dt` 标签与 `dl`(定义一个描述列表)和 `dd` (描述每一个项目/名字)一起使用.
9. `dt` 标签
10. `dd` 标签
11. `figure` 标签: `figure` 标签规定独立的流内容(图像、图表、照片、代码等等). `figure` 标签的内容应该与主内容相关,同时标签的位置相对于主内容是独立的.如果被删除,则不应对文档流产生影响.
12. `figcaption` 标签: `figcaption` 标签为 `figure` 标签定义标题.它被置于 `figure` 标签的第一个或最后一个子标签的位置.
13. `div` 标签: `div` 标签没有任何特殊含义, 当没有其他标签适合时,再使用此标签.使用它来控制其内部样式.
14. `main` 标签: `main` 标签代表文档或应用程序 `body` 的主要内容.主要内容包括与文档的中心主题或应用程序的核心功能直接相关或扩展的内容.
15. `details`标签: `details` 标签定义可折叠的交互式控件.
16. `summary`标签: `summary` 标签提供可见的标题,点击可切换内容显示状态.

## 文本级语义

1. `a` 标签: `a` 标签定义超链接,用于从一个页面链接到另一个页面.
2. `em` 标签: `em` 标签是一个短语标签,用来呈现为被强调的文本.
3. `strong` 标签: `strong` 标签定义重要的文本.
4. `small` 标签: `small` 标签表示旁注或小字内容(如版权声明),不适用于强调文本.
5. `s` 标签: `s` 标签对那些不正确、不准确或者没有用的文本进行标识.
6. `cite` 标签: `cite` 标签定义引用、引证
7. `q` 标签: `q` 标签定义短的引用语.
8. `dfn` 标签: `dfn` 标签标记术语的定义实例,常与 `abbr` 或上下文解释配合使用.
9. `abbr` 标签: `abbr` 标签用来表示一个缩写词或者首字母缩略词,如 "WWW" 或者 "NATO".
10. `data` 标签: `data` 标签用于添加给定内容的机器可读翻译.
11. `time` 标签: `time` 标签定义了特定的时间(或日期时间).
12. `code` 标签: `code` 标签定义计算机代码文本.
13. `var` 标签: `var` 标签定义变量. 您可以将此标签与 `pre` 及 `code` 标签配合使用.
14. `samp` 标签: `samp` 标签定义样本文本.
15. `kbd` 标签: `kbd` 标签定义键盘文本. 它表示文本是从键盘上键入的.它经常用在与计算机相关的文档或手册中.
16. `sub` 和 `sup` 标签: `sub` 标签定义下标字. `sup` 标签定义上标字.
17. `i` 标签: `i` 标签定义斜体字.
18. `b` 标签: `b` 标签定义粗体文本.
19. `u` 标签: `u` 标签为文本添加下划线.
20. `mark` 标签: `mark` 标签定义带有记号的文本. 显示为高亮内容.
21. `ruby` 标签: `ruby` 标签与 `rp` 和 `rt` 标签一起使用
22. `rp` 标签: `rp` 标签在 `ruby` 注释中使用,以定义不支持 `ruby` 标签的浏览器所显示的内容.
23. `rt` 标签: `rt` 标签定义字符(中文注音或字符)的解释或发音
24. `rtc` 标签: `rtc` 标签
25. `rb` 标签: `rb` 标签
26. `bdi` 标签: `bdi` 标签允许您设置一段文本,使其脱离其父标签的文本方向设置.在发布用户评论或其他您无法完全控制的内容时,该标签很有用. 如阿拉伯语方向是反的.
27. `bdo` 标签: `bdo` 标签用来覆盖默认的文本方向.
28. `span` 标签: `span` 标签本身没有任何意义,使用它来单独控制内部样式.
29. `br` 标签: `br` 标签插入一个简单的换行符
30. `wbr` 标签: `wbr` 标签规定在文本中的何处适合添加换行符.
31. `ins` 标签: `ins` 标签定义已经被插入文档中的文本.
32. `del` 标签: `del` 标签定义文档中已删除的文本.

## 表格

1. `table` 标签: `table` 标签定义 HTML 表格.
2. `caption` 标签: `caption` 标签定义表格的标题
3. `colgroup` 标签: `colgroup` 标签用于对表格中的列进行组合,以便对其进行格式化.
4. `col` 标签: `col` 标签规定了 `colgroup` 标签内部的每一列的列属性
5. `tbody` 标签: `tbody` 标签用于组合 HTML 表格的主体内容.该三组标签以前用于使用 table 来定义文本样式.
6. `thead` 标签: `thead` 标签用于组合 HTML 表格的表头内容.
7. `tfoot` 标签: `tfoot` 标签用于组合 HTML 表格的页脚内容.
8. `tr` 标签: `tr` 标签定义表格行.
9. `td` 标签: `td` 标签定义表格单元.
10. `th`标签: `th`标签定义表头.

## 表单

1. `form` 标签: `form` 标签用于创建供用户输入的 HTML 表单.
2. `label` 标签: `label` 标签为 input 标签定义标注(标记).
3. `input` 标签: `input` 标签规定了用户可以在其中输入数据的输入字段.
4. `button` 标签: `button` 标签定义一个按钮.
5. `select` 标签: `select` 标签用来创建下拉列表.
6. `datalist` 标签: `datalist` 标签被用来在为 `input` 标签提供自动完成的特性.用户能看到一个下拉列表,里边的选项是预先定义好的,将作为用户的输入数据.
7. `optgroup` 标签: `optgroup` 标签用于把相关的选项组合在一起.与 `select`, `option` 一起使用.
8. `option` 标签: `option` 标签定义下拉列表中的一个选项.
9. `textarea` 标签: `textarea` 标签定义一个多行的文本输入控件.
10. `output` 标签: `output` 标签作为计算结果输出显示(比如执行脚本的输出).
11. `progress` 标签: `progress` 标签定义运行中的任务进度(进程).
12. `meter` 标签: `meter` 标签定义度量衡.仅用于已知最大和最小值的度量.
13. `fieldset` 标签: `fieldset` 标签可以将表单内的相关标签分组.`fieldset` 标签会在相关表单标签周围绘制边框.
14. `legend` 标签: `legend` 标签为 `fieldset` 标签定义标题.
15. `dialog` 标签: `dialog` 标签定义一个对话框、确认框或窗口.

## 嵌入式内容

1. `img` 标签: `img` 标签定义 HTML 页面中的图像.
2. `iframe` 标签: `iframe` 标签规定一个内联框架.一个内联框架被用来在当前 HTML 文档中嵌入另一个文档.
3. `embed` 标签: `embed` 标签定义了一个容器,用来嵌入外部应用或者互动程序(插件).**尽管可用性降低，但在嵌入第三方插件（如 PDF 查看器）时仍可能用到。**
4. `object` 标签: `object` 标签用于包含对象,比如图像、音频、视频、Java applets、ActiveX、PDF 以及 Flash.
5. `param` 标签: `param` 标签可为包含它的 `object` 或者 `applet` 标签提供参数.
6. `video` 标签: `video` 标签定义视频,比如电影片段或其他视频流.支持 3 种视频格式：MP4、WebM、Ogg.
7. `audio` 标签: `audio` 标签定义声音,比如音乐或其他音频流.支持的 3 种文件格式：MP3、Wav、Ogg.
8. `source` 标签: `source` 标签为媒体标签(比如 `video` 和 `audio`)定义媒体资源.
9. `track` 标签: `track` 标签为媒体标签(比如 `video` 和 `audio`)规定外部文本轨道,也就是字幕.
10. `map` 标签: `map` 标签用于客户端图像映射.图像映射指带有可点击区域的一幅图像.`img` 中的 usemap 属性可引用 `map` 中的 id 或 name 属性.
11. `area` 标签: `area` 标签定义图像映射内部的区域(图像映射指的是带有可点击区域的图像).嵌套在 `map` 标签内部.
12. `svg` 标签: `svg` 标签

## 脚本

1. `script` 标签: `script` 标签用于定义客户端脚本,比如 JavaScript.
2. `noscript` 标签: `noscript` 标签用来定义在脚本未被执行时的替代内容(文本).
3. `template` 标签: `template` 标签定义在页面加载时隐藏的一些内容,该标签中的内容可以稍后使用 JavaScript 呈现.
4. `canvas` 标签: `canvas` 标签通过脚本(通常是 JavaScript)来绘制图形(比如图表和其他图像).
