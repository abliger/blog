# 工具集成

## pretty

```bash
pnpm install pretty
```

添加忽略文件

```txt
**/node_modules/**
project/** 
doc/** 
game/** 
.vitepress/cache/**
.vitepress/dist/**
*-lock.yaml
.idea
.vscode
```

添加配置文件

```ts
import { type Config } from 'prettier'

export default {
    trailingComma: 'all', //尾随逗号
    tabWidth: 4,
    useTabs: false,
    semi: false, // 末尾分号
    singleQuote: true, // 单引号
    bracketSpacing: true, // 对象中使用空格和内容分开
    bracketSameLine: false, //将多行 HTML（HTML、JSX、Vue、Angular）元素的 > 放在最后一行的末尾，而不是单独放在下一行（不适用于自闭元素）。
    arrowParens: 'avoid', // 箭头函数括号 尽可能省略括号
    vueIndentScriptAndStyle: true,
} as Config
```

添加执行命令

```json
{
 "prettier": "prettier --write .",
}
```

## husky、lint-staged、commitizen、cz-git 和 commitlint 集成

```bash
pnpm install -D @commitlint/cli @commitlint/config-conventional husky
pnpm exec husky init
```

配置提交消息钩子

```bash
# 向 commit-msg 钩子添加提交消息校验
echo "pnpm dlx commitlint --edit \$1" > .husky/commit-msg
# Windows 用户应该使用 ` 来转义美元符号
echo "pnpm dlx commitlint --edit `$1" > .husky/commit-msg
```

在 package.json 中添加 lint-staged 配置

```json
{
     "lint-staged": {
        "*.{vue,js,ts,jsx,tsx,md,json}": [
            "eslint --fix --concurrency=auto",
            "prettier --write --experimental-cli"
        ]
    }
}
```

添加 commitizen 配置

```json
{
  "config": {
        "commitizen": {
            "path": "node_modules/cz-git"
        }
    },
}
```
